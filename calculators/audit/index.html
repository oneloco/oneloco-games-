What columns does the file need?

One row per quote request. Only the created date is required. The more columns you include, the less you have to estimate.

Pull the last 90 days straight from a HighLevel sub-account. Create a Private Integration in Settings > Private Integrations with only two read scopes: View Opportunities and View Conversation Messages. Delete it when you're done.
